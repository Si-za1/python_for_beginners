## **Week 1: Python Basics & Fundamentals**  
### **Goals for the Week:**  
✅ Understand Python syntax, variables, and data types.  
✅ Learn basic operations, string manipulations, and collections.  
✅ Get comfortable writing simple Python programs.  
✅ Build a small **To-Do List CLI App** as your first project.  

---

### **Day 1: Introduction to Python & Setup**  
📌 **Topics to Learn:**  
- What is Python? Why learn Python?  
- Installing Python and setting up your environment (IDLE, VS Code, Jupyter Notebook).  
- Writing your first Python program: `print("Hello, World!")`.  
- Understanding Python syntax (indentation, comments).  

💻 **Exercises:**  
1. Install Python and set up your coding environment.  
2. Write a simple script that prints your name, age, and a short introduction.  

🔗 **Resources:**  
- [Python Installation Guide](https://realpython.com/installing-python/)  
- [Python Syntax & Basics (W3Schools)](https://www.w3schools.com/python/python_syntax.asp)  

---

### **Day 2: Variables & Data Types**  
📌 **Topics to Learn:**  
- Variables: Naming rules, assigning values.  
- Data types: `int`, `float`, `str`, `bool`, `complex`.  
- Type conversion (`int()`, `str()`, `float()`).  

💻 **Exercises:**  
1. Create variables for name, age, and height and print them.  
2. Convert an integer to a float and vice versa.  
3. Swap two variables without using a third variable.  

🔗 **Resources:**  
- [Python Variables (W3Schools)](https://www.w3schools.com/python/python_variables.asp)  
- [Python Data Types (GeeksForGeeks)](https://www.geeksforgeeks.org/python-data-types/)  

---

### **Day 3: Operators in Python**  
📌 **Topics to Learn:**  
- Arithmetic operators: `+`, `-`, `*`, `/`, `%`, `**`, `//`  
- Comparison operators: `==`, `!=`, `>`, `<`, `>=`, `<=`  
- Logical operators: `and`, `or`, `not`  
- Bitwise operators (optional)  

💻 **Exercises:**  
1. Create a simple calculator program.  
2. Write a program to check if a number is even or odd.  
3. Use logical operators to check if a number is in a given range.  

🔗 **Resources:**  
- [Python Operators (W3Schools)](https://www.w3schools.com/python/python_operators.asp)  
- [Arithmetic Operators (RealPython)](https://realpython.com/python-operators-expressions/)  

---

### **Day 4: Strings & String Manipulation**  
📌 **Topics to Learn:**  
- Strings: How to create and manipulate them.  
- String methods: `.upper()`, `.lower()`, `.strip()`, `.replace()`, `.split()`.  
- String formatting: `f""`, `.format()`, `%` operator.  

💻 **Exercises:**  
1. Write a program to take a user’s full name and return it in uppercase and lowercase.  
2. Replace all spaces in a sentence with underscores.  
3. Extract the first three characters of a string and reverse them.  

🔗 **Resources:**  
- [Python Strings (W3Schools)](https://www.w3schools.com/python/python_strings.asp)  
- [String Methods (Python Docs)](https://docs.python.org/3/library/stdtypes.html#string-methods)  

---

### **Day 5: Lists, Tuples, and Sets**  
📌 **Topics to Learn:**  
- Lists: How to create, modify, and access elements.  
- Tuples: Immutable collections.  
- Sets: Unordered, unique elements.  

💻 **Exercises:**  
1. Create a list of your favorite movies and print the first three.  
2. Convert a list to a tuple and vice versa.  
3. Use a set to remove duplicate items from a list.  

🔗 **Resources:**  
- [Lists in Python (W3Schools)](https://www.w3schools.com/python/python_lists.asp)  
- [Tuples in Python (RealPython)](https://realpython.com/python-lists-tuples/)  

---

### **Day 6: Dictionaries in Python**  
📌 **Topics to Learn:**  
- Creating dictionaries.  
- Accessing, modifying, and deleting dictionary values.  
- Dictionary methods: `.keys()`, `.values()`, `.items()`.  

💻 **Exercises:**  
1. Create a dictionary for a person’s details (name, age, city).  
2. Retrieve and print only the keys and values separately.  
3. Check if a specific key exists in a dictionary.  

🔗 **Resources:**  
- [Dictionaries in Python (W3Schools)](https://www.w3schools.com/python/python_dictionaries.asp)  
- [Python Dictionaries (RealPython)](https://realpython.com/python-dicts/)  

---

### **Day 7: Project – To-Do List CLI App**  
📌 **Project Description:**  
Build a **command-line To-Do List application** where a user can:  
- Add new tasks.  
- View existing tasks.  
- Mark tasks as completed.  
- Delete tasks.  

💻 **Steps to Build:**  
1. Create a menu system (`1. Add Task  2. View Tasks  3. Mark Task Complete  4. Delete Task`).  
2. Store tasks in a Python list or dictionary.  
3. Use loops and conditionals to manage tasks.  

🔗 **Helpful Resources:**  
- [Basic Python Projects (Beginner)](https://realpython.com/python-projects-beginners/)  
- [Python Input & Output](https://www.w3schools.com/python/python_input.asp)
